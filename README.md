# Task 25 – Basic Data Validation

## Project Overview

This project is part of Task 25 of the Veda Technology Internship. The main objective is to understand and implement basic data validation techniques in Microsoft Excel to maintain accurate, consistent, and error-free data.

## 🎯 Objectives

- Understand basic data validation in Excel.
- Create dropdown lists for selecting values.
- Set minimum and maximum limits for numeric values.
- Validate employee age and salary.
- Restrict date entries within a specific range.
- Prevent incorrect data entry.

## 🛠️ Tools Used

- Microsoft Excel
- Data Validation
- Excel Dropdown Lists

## 📊 Dataset Description

The project uses an Employee Dataset containing the following columns:

- Employee ID
- Employee Name
- Department
- Age
- Salary
- Job Type
- Joining Date

## ⚙️ Data Validation Techniques

1. **Department Validation:** Created a dropdown list containing HR, IT, Finance, Marketing, and Sales.
2. **Age Validation:** Restricted employee age between 18 and 60.
3. **Salary Validation:** Allowed salary values between 10,000 and 2,00,000.
4. **Job Type Validation:** Created a dropdown list containing Full-Time, Part-Time, and Intern.
5. **Joining Date Validation:** Restricted dates between 01-01-2020 and 31-12-2026.

## ✅ Key Outcomes

- Successfully implemented data validation rules in Excel.
- Created dropdown lists for easy data entry.
- Reduced incorrect and invalid data entries.
- Improved data accuracy and consistency.
- Learned practical Excel data management techniques.
